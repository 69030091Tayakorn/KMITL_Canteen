# QR สำหรับสาธิต

วางรูป QR บัญชีทดสอบชื่อ `payment_qr.png` ในโฟลเดอร์นี้
ไฟล์รูปส่วนตัวไม่รวมใน Git หากไม่มีรูป แอปจะแจ้งเตือนและปิดปุ่มแจ้งชำระ

หน้านี้ใช้สาธิตการแจ้งชำระเท่านั้น ไม่ตรวจเงินเข้า ไม่แนบสลิป และไม่ยืนยันว่าชำระสำเร็จ
ออเดอร์ใหม่ใช้สถานะ `awaiting_payment_review` เพื่อรอการตรวจสอบ ส่วนออเดอร์เก่าไม่เปลี่ยนสถานะ
