# ขั้นแรกของระบบบัญชี: ตารางใน SQLite

ไฟล์ `01_add_users.sql` สำหรับฐานข้อมูลเดิมที่ยังไม่มีตาราง users และคอลัมน์ orders.user_id / orders.shop_id รันครั้งเดียว ไม่ใช่สคริปต์เปิดแอป

1. ปิดแอป KMITL Canteen ชั่วคราว และบันทึกงานค้างใน DB Browser
2. เปิด `D:\Canteen_project\Database SQLite\canteen.db` ตรวจชื่อไฟล์บนแถบหน้าต่าง
3. แท็บ Execute SQL เปิดไฟล์ `01_add_users.sql` แล้วรันทั้งหมด
4. ต้องขึ้นว่าไม่มีข้อผิดพลาด จากนั้นกด Write Changes ถ้าปุ่มเปิดใช้งาน
5. ดูตาราง users ใน Database Structure และคอลัมน์ user_id / shop_id ใน orders

สคริปต์ใช้ SAVEPOINT เพื่อทำงานร่วมกับ transaction ที่ DB Browser เปิดไว้ หลังรันสำเร็จให้กด Write Changes เพื่อบันทึกลงไฟล์

ถ้ามีข้อผิดพลาด อย่ารันซ้ำทันที ให้ส่งข้อความผิดพลาดมาตรวจ หากสคริปต์เริ่ม SAVEPOINT แล้วแต่ยังไม่ถึง RELEASE สามารถย้อนกลับเฉพาะงานชุดนี้ด้วย `ROLLBACK TO SAVEPOINT add_users_migration;` แล้ว `RELEASE SAVEPOINT add_users_migration;` ไม่ใช้ ROLLBACK ทั้งหมด เพราะอาจย้อนงานอื่นที่ค้างอยู่ด้วย

## ความหมาย

- user_id: รหัสบัญชี
- username: ชื่อเข้าสู่ระบบ ไม่ซ้ำและไม่แยกตัวพิมพ์ใหญ่เล็กสำหรับอักษร ASCII
- password_hash: เก็บค่าแฮชพร้อมข้อมูลที่ใช้ตรวจรหัสผ่าน ไม่ใช่รหัสผ่านตรง ๆ ให้ Python สร้างในขั้นต่อไป
- display_name: ชื่อแสดงในแอป
- role: customer = ลูกค้า, shop = ร้านค้า
- users.shop_id: บัญชีร้านผูกกับร้านเดียว ลูกค้าไม่มีรหัสร้าน
- orders.user_id: เจ้าของออเดอร์
- orders.shop_id: ร้านที่รับออเดอร์โดยอ้างรหัส ไม่ใช่ชื่อร้าน

ออเดอร์เก่ายังมี user_id และ shop_id เป็น NULL ไม่ถูกนำไปผูกกับผู้ใช้ใหม่หรือร้านโดยเดาเอง ข้อมูลอาหารและราคาเดิมคงอยู่

หลังอัปเดต Python แอปจะเริ่มที่หน้าเข้าสู่ระบบ ลูกค้าสมัครได้จากหน้าแอป รหัสผ่านถูกแฮชด้วย PBKDF2-SHA256 พร้อม salt สุ่ม ไม่กรอกรหัสผ่านตรง ๆ ลง password_hash

บัญชีร้านให้ผู้ดูแลเครื่องสร้างจากโฟลเดอร์โปรเจกต์ด้วย `python -m Backend.create_shop_account` หน้าต่างสร้างบัญชีร้านจะเปิดขึ้น เลือกร้านจากรายการและกรอกข้อมูลบัญชี ติ๊กแสดงรหัสผ่านได้ เครื่องมือนี้เพิ่มบัญชีใน SQLite โดยไม่เปลี่ยน schema ร้านค้าไม่สามารถสมัครเลือกสิทธิ์เองจากหน้าแอป

ลูกค้าอ่านได้เฉพาะออเดอร์ที่มี user_id ของตัวเอง ร้านอ่านและเปลี่ยนสถานะได้เฉพาะ shop_id ของบัญชี ออเดอร์เก่าที่ไม่มีรหัสเหล่านี้ยังเก็บอยู่ ดูได้จาก DB Browser แต่ไม่ปรากฏในบัญชีใหม่

การแยกสิทธิ์นี้ใช้ในแอป Desktop เครื่องเดียว ผู้ที่เข้าถึงไฟล์ SQLite หรือโค้ดบนเครื่องยังแก้ข้อมูลโดยตรงได้ ยังไม่ใช่ระบบเซิร์ฟเวอร์หลายเครื่อง

สำหรับเครื่องใหม่ ให้รัน schema.sql และ sample_data.sql ตามขั้นตั้งค่าเดิม แล้วรัน 01_add_users.sql อีกครั้งเดียวเพื่อเพิ่มโครงสร้างบัญชี
